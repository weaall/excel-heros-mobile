# 블루아카이브 레퍼런스 분석 — 수치로

`temp_images/`의 실제 스크린샷을 잘라서 잰 값이다. 해상도가 제각각이라 전부 **화면 높이 대비 비율**로 적고,
우리 기준(2400×1080)으로 환산한 값을 괄호에 둔다. "비슷하게"가 아니라 이 숫자에 맞춘다.

> 참고하는 것: 배치, 비율, 재질, 색, 글씨, 움직임. **참고하지 않는 것**: 캐릭터, 로고, 고유 명칭(청휘석·선생님·모모톡 등).

## 4. 아이콘 스타일

선 아이콘(Material Symbols)은 블루아카와 가장 멀다. 블루아카 아이콘은 **작은 삽화**다.

- 짙은 남색 외곽선(2~3px 상당), 셀 셰이딩 2단, 위쪽 흰 광택
- 사물 하나를 3/4 각도로(확성기, 휴대폰, 클립보드, 쇼핑백, 컵)
- 색은 사물마다 다르지만 채도는 파스텔 쪽
- 잠긴 기능은 아이콘 위에 **자물쇠**를 겹친다

→ 우리 아이콘은 **회사 사물**로 같은 스타일: 사원증, 조직도 보드, 체크리스트, 돋보기+서류, 분홍 휴대폰(메신저),
사진 앨범, 바인더(도감), 모니터 막대그래프(통계), 모집 봉투, 사옥(로비), 확성기(공지), 쇼핑백(상점),
금화(골드), 보석(보석), 톱니(설정), 집(홈), 편지(우편).

## 5. 상호작용 · 소리

| 무엇 | 블루아카 | 적용 |
|---|---|---|
| 버튼 누름 | 0.94까지 줄었다가 **살짝 튕기며** 복귀 | 눌림 0.94 → 떼면 1.04 → 1.0 (스프링) |
| 터치 자리 | 하늘색 **작은 고리 + 삼각 조각**이 퍼짐 | 화면 어디를 눌러도 터치 효과 |
| 화면 전환 | 패널이 옆에서 **미끄러져 들어오고** 흰 섬광 | 새 화면 0.18초 슬라이드 + 페이드 |
| 탭 소리 | 짧고 밝은 **"퐁"** (고음, 부드러운 어택) | 사인파 + 빠른 피치 하강, 40ms |
| 확인 소리 | 두 음 상행 | 확인·획득 |
| 뒤로 소리 | 짧게 하행 | 뒤로가기·닫기 |

## 6. 모바일 감각

- 글자를 줄인다. 블루아카 로비에 **문장은 말풍선 하나뿐**이다.
- 누르는 것은 크게: 아이콘 86~96px, 버튼 높이 100px 이상.
- 정보 밀도가 높은 목록(필터 칩 줄 등)은 모바일에서는 탭 한 줄로 줄인다.
